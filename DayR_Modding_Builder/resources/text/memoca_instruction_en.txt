!!Heading!! Welcome to Day R Modding Tool (version 0.0.2)!

This program automates mod creation for Day R Survival (version 1.694 and below). It handles unpacking the game archive, decompiling scripts, compiling modified files, and packing the mod without requiring extra tools.

Program settings are saved in the user folder:
C:\Users\<Username>\DayR_MB\settings.ini
This allows you to keep your chosen font and other settings even when moving the EXE file.

!!Heading!! System Requirements
- Windows 7/8/10/11 (32 or 64 bit)
- RAM from 512 MB
- Free space: ~100 MB for the tool + ~2 GB for game files
- Write permissions in the working folder

!!Heading!! Installation and Launch
1. Download DayR_Modding_Tool.exe
2. Place it anywhere convenient (Desktop or a separate folder)
3. Run it by double-clicking

Antivirus may ask for an exception on first run — the program is safe, all embedded utilities are legal.

!!Heading!! Interface Overview
- Top panel: language selection (Russian/English), Profiles button, Settings button (gear), Help button (?)
- Project panel: folder path and "Open mod_scripts folder" button
- Main buttons (four rows):
  - Row 1: Unpack, decompile, mass compile (warning)
  - Row 2: Pack mod, clean project, file manager
  - Row 3: Compile one .lua, decompile one .lu, select resource.car
  - Row 4: Reset mod_scripts, clear modded_lu, Lua console
- Log window: displays messages and errors
- Bottom panel: status, "Save logs", and "Clear log" buttons

!!Heading!! Step‑by‑Step Workflow
1. Choose a project folder (empty or existing).
2. Copy resource.car from the game (assets folder) into the resources folder inside your project, or click "Select resource.car" to pick the file.
3. Click "Unpack resource.car" – all files are extracted into original_scripts.
4. Click "Decompile all .lu → .lua" – you get readable code in mod_scripts.
5. Edit the needed .lua files (use the built-in editor or external editor) inside mod_scripts.
6. Open "File Manager", find your edited file, and click "Build" – it compiles to .lu and goes into modded_lu.
   Repeat for all changed files.
7. Click "Pack resource.car (mod)" – choose where to save the new resource.car.
8. Copy the resulting file into the game folder (backup the original) and launch the game.

!!Frame!!
Important: Never use the "Compile all .lua → .lu" button – it recompiles everything and almost always breaks the game! This button is red and requires confirmation.
!!EndFrame!!

!!Heading!! Profile Management
- Profiles allow you to save project settings and quickly switch between different mods.
- Open the profile manager via the "Profiles" button in the top panel.
- Create, edit, select, delete, export, and import profiles.
- Export: creates a .dayr archive with the entire project folder.
- Import: unpacks a .dayr and automatically creates a profile.

!!Heading!! Built‑in Editor
- In File Manager, the "Open" button launches the built-in editor.
- Syntax highlighting (if pygments is installed).
- Buttons: "Save", "Save and compile", "Close".
- "Save and compile" – saves and compiles the file to modded_lu.

!!Heading!! Lua Console
- Open via the "Lua console" button in row 4.
- Enter code, click "Run" or press Ctrl+Enter.
- Result appears in the output field.
- Convenient for testing small scripts.

!!Heading!! Font Settings
1. Click the Settings button (gear icon) in the top panel.
2. Select one of the available fonts: Classic, RO.ttf (Red October), freemono.ttf, russo_one.ttf.
3. If the font is missing, the program will offer to open the folder to add the .ttf file.
4. Click "Save" and restart the program.

!!Heading!! Frequently Asked Questions
❓ Why is _temp_extract empty but files appear in the project root?
This is a corona-archiver.py quirk – the program automatically moves files to original_scripts. Ignore it.

❓ Game won't start after installing the mod?
Make sure you didn't use the forbidden button. Check that you compiled only changed files and they ended up in modded_lu with the correct structure. Try "Reset mod_scripts" and recompile.

❓ How to restore original files after editing?
Use "Reset mod_scripts" – it will delete modified .lua and recreate them from originals.

❓ How to add my own font?
Place your .ttf file in the font folder (next to the EXE or in resources) and select it in settings.

❓ Can I use the tool with other game versions?
The tool has been tested on versions 1.683 and 1.694. For versions newer than 1.694, the file structure may differ – use at your own risk.
