!!Heading!! Overview of Main Game Files (Full List)

This document lists all key files and folders of Day R Survival version 683, grouped by functional areas. Each file or group of files is accompanied by a brief explanation of its purpose.

!!Heading!! 1. Core Modules and Game Engine
- lib.class.lua – fundamental OOP module (classes, inheritance).
- lib.class_graphic.lua – management of graphical objects and UI panels.
- lib.class_story.lua – factory for story/random event systems.
- lib.cache.lua – in‑memory data caching.
- lib.calculate.lua – central calculation of game parameters (time, lighting, speed, load, radiation, etc.).
- lib.constants.lua – global constants (screen size, platform, etc.).
- lib.converter.lua – data conversion utilities (time, numbers, weight, currency).
- lib.game.lua – main game management (loading/saving, timers, pause).
- lib.gameNetwork.lua – integration with Game Center (iOS) and Google Play Games (Android).
- lib.filework.lua – file operations (encrypted saves with HMAC‑SHA512).
- lib.ksark.lua – internal testing utilities (does not affect gameplay).
- lib.loading_master.lua and lib.loading_list.lua – loading screen and module initialisation.
- lib.table2.lua – table utilities (copy, search, merge, etc.).
- lib.version_switch.lua – save migration on version update.
- main.lua – main initialisation file (global variables, library loading, screen setup).

!!Heading!! 2. Battle System

!!Heading!! 2.1 Battle Core
- lib.battle.battle_master.lua – main battle module (init, turns, win/loss).
- lib.battle.battle_map.lua and battle_map_list.lua – battle map management (cells, walls, pathfinding, visibility).
- lib.battle.unit.lua – unit logic (creation, movement, attack, taking damage).
- lib.battle.unit_method.lua – helper methods for units (stat calculation, action access).
- lib.battle.unit_attack.lua – handling various attack types (area, flank, flamethrower, etc.).
- lib.battle.faction.lua and faction_list.lua – factions (relations, initiative).
- lib.battle.terrain.lua and terrain_list.lua – terrain types on the battlefield.
- lib.battle.perk.lua and perk_list.lua – battle perks (loading, conditions, application).
- lib.battle.effect.lua and effect_list.lua – battle effects (poison, bleeding, burn, etc.).

!!Heading!! 2.2 Artificial Intelligence
- lib.battle.ai.lua – main enemy AI (target selection, attacks, movement).
- lib.battle.ai_unit_ap.lua – AI for units with Action Points (hero, powerful enemies).

!!Heading!! 2.3 Weapons
- lib.battle.weapon.lua – weapon class (loading lists, damage, range, AP calculation).
- lib.battle.weapon_method.lua – helper methods for weapons.
- lib.battle.weapon_list.lua, weapon_halloween_list.lua, weapon_new_year_list.lua – weapon lists (main and event‑themed).

!!Heading!! 2.4 Unit Lists
- lib.battle.unit_template_list.lua – unit templates.
- lib.battle.unit_ally_list.lua – allied units (hero, pets).
- lib.battle.unit_animal_list.lua – animals and mutants.
- lib.battle.unit_bandit_list.lua – bandits and marauders.
- lib.battle.unit_halloween_list.lua – Halloween monsters.
- lib.battle.unit_new_year_list.lua – New Year enemies.
- lib.battle.unit_event_list.lua – units for story events and quests.
- lib.battle.unit_phrase.lua and unit_phrase_list.lua – unit battle phrases.

!!Heading!! 2.5 Enemy Groups
- lib.battle.enemy.lua – main enemy module (loading lists, encounter, loot, respawn).
- lib.battle.enemy_animal_list.lua – animal groups.

- lib.battle.enemy_halloween_list.lua – Halloween enemy groups.
