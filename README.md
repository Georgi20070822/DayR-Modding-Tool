# DayR-Modding-Tool
Eu: A graphical modding tool for the game Day R Survival. Allows you to unpack resource.car, decompile/compile scripts and build mods.
Ru: Графический инструмент для моддинга игры Day R Survival. Позволяет распаковывать resource.car, декомпилировать/компилировать скрипты и создавать моды.
